# Calculator

## About the Project

Calculator is a simple application developed to create something independently and improve programming skills. It performs basic arithmetic operations through a user-friendly interface.

## Objectives

* To create a simple calculator application independently.
* To practice programming concepts.
* To understand how arithmetic operations work in an application.
* To develop a user-friendly interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Easy-to-use interface
* Displays the calculation result

## Technologies Used

* Go

## How to Run

1. Install Go on your computer.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run the program using:

```bash
go run main.go
```
